The simple infrastructure published here addresses the need to simplify the configuration of user interface culture.
The elements of the solution are represented:
- from the C# Localization.cs class;
- from the javascript class Localization.js;
- from the partial UserCulture.cshtml view.

Localization.cs allows for immediate service configuration within the Program.cs class and exposes a few simple static methods for retrieving and modifying the user's chosen language.
The Localization.js javascript class and the UserCulture.cshtml partial view allow you to add a menu for the user's language shortcut.
When choosing, Localization will invoke the submit of the form characterized by the pseudo class "localization" or, in its absence, of the first form element found within the DOM of the page. A hidden input element with the selected culture value will be added dynamically shortly before the submit.
If necessary, you can cancel the submit by intercepting the "ChangeCultureRequest" event generated by Localization by setting its "submitform" attribute to the value false.
Recording the choice will be done within the Action by simply invoking the "public static void SetCultureInfoOnPostBack(HttpContext Context)" method of the Location.cs class.
